# SatyamOS v5.0

Story-driven portfolio experience built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, GSAP, Three.js, React Icons, and Lenis.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The resume download endpoint is a placeholder build artifact.
